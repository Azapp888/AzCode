# AzCode (Android)

[简体中文](zh-CN.md) | [English](en.md) | [日本語](ja.md) | [한국어](ko.md) | [Français](fr.md) | [Deutsch](de.md) | [Español](es.md)

AzCode — локальный ассистент автоматизации для Android. Опишите задачу на естественном языке, и встроенный цикл агента прочитает экран, нажмёт элементы, выполнит свайпы и команды через службу специальных возможностей, пока задача не будет решена. Все данные остаются на устройстве, без облачной синхронизации.

- Имя приложения: **AzCode**
- Метка графического интерфейса: **magic**
- Метка командной строки: **Listen**
- Текущая версия: **1.9.15** (versionCode 70)
- Требования: Android 8.0+ (minSdk 26), targetSdk 34

AzCode работает автономно либо открывает мост возможностей, привязанный только к `127.0.0.1:8848`, чтобы CLI Listen и другие клиенты могли использовать те же функции устройства через `adb forward`.

## Быстрый старт

### Установка

Скачайте APK из GitHub Releases версии `android-v*` либо возьмите артефакт `azcode-magic-apk` из GitHub Actions. Сборки debug и release используют один и тот же ключ подписи из репозитория, поэтому могут устанавливаться поверх друг друга.

### Первая настройка

1. Откройте «Настройки > Возможности устройства > Специальные возможности» и включите **AzCode Screen Control** в системных настройках.
2. Перейдите в «Настройки > Управление моделями», добавьте и включите провайдера, введите API Key. Base URL и модель можно выбрать из шаблонов.
3. Вернитесь на главный экран и подтвердите активную модель в селекторе.
4. Введите задачу и отправьте её, например «Открой настройки и покажи версию Android».

### Разрешения

| Разрешение | Назначение |
| --- | --- |
| Служба специальных возможностей | Чтение экрана, нажатия, свайпы, системная навигация, ввод текста |
| Микрофон | Голосовой ввод и плавающий ассистент |
| Уведомления | Уведомления о завершении задач и вопросах |
| Показ поверх других приложений | Свечение плавающего ассистента |
| Камера | Вложения-фотографии |
| Termux RUN_COMMAND | Выполнение полных команд Linux через Termux |
| Shizuku | Выполнение системных команд от имени adb |

### Сборка из исходников

Нужны JDK 17 и Android SDK. В репозитории нет `gradle-wrapper.jar`, поэтому используйте системный `gradle`:

```bash
gradle assembleDebug
gradle assembleRelease
```

После отправки кода `.github/workflows/android.yml` соберёт Debug и Release APK в GitHub Actions. Пуш тега `android-v*` создаёт GitHub Release.

## Возможности устройства и выполнение команд

| Режим | Канал | Идентичность | Условие | Таймаут |
| --- | --- | --- | --- | --- |
| NORMAL + Termux | Termux `RUN_COMMAND` | uid Termux | Termux установлен, RUN_COMMAND разрешён, `allow-external-apps=true` | 90 с |
| NORMAL + встроенный shell | `/system/bin/sh -c` | uid приложения | Нет | 60 с |
| SHIZUKU | Shizuku binder | adb uid 2000 | Shizuku запущен и авторизован | 60 с |
| ROOT | `su -c` | uid 0 | Устройство рутировано | 60 с |

Режим NORMAL сначала пробует Termux и возвращается к встроенному shell. Доступ к приватным каталогам других приложений и изменение системных настроек требуют Shizuku или Root.

## Локальные данные и хранилище

AzCode не использует SQLite, Room или серверную базу данных. Слой данных — приватные для приложения `SharedPreferences` и файлы JSON:

| Путь | Содержимое |
| --- | --- |
| `SharedPreferences` | Провайдеры моделей, курсор сессии, навыки, память команд, конфигурация GitHub / GenOffice, режим голоса и привилегий |
| `files/sessions/<id>.json` | История чата и контекст агента одной сессии |
| `files/memory.json` | Записи долговременной памяти |
| `files/logs/YYYY-MM-DD.log` | Ежедневные ротируемые журналы, до 10 файлов, 512 КБ на файл |
| `files/genoffice/` | Созданные документы Office |
| `cache/az_images/`, `cache/captures/` | Кэш изображений и временные файлы съёмки |

Сессии записываются временным файлом с переименованием. Контекст агента хранит не более 40 сообщений, более старые сжимаются в сводку. Удаление приложения стирает все локальные данные.

## Мост возможностей и CLI Listen

Мост слушает только `127.0.0.1:8848`, недоступен из интернета и не имеет аутентификации. Удалённый доступ требует `adb forward`.

| Метод | Путь | Описание |
| --- | --- | --- |
| GET | `/health` | Состояние специальных возможностей, Shizuku, Root и режима привилегий |
| GET | `/screen` | Видимые узлы экрана, до 200 |
| POST | `/tap` | `{"x":123,"y":456}` или `{"text":"OK"}` |
| POST | `/swipe` | `{"x1":..,"y1":..,"x2":..,"y2":..,"duration":300}` |
| POST | `/global` | `{"action":"back"}`, поддерживает back / home / recents / notifications |
| POST | `/shell` | `{"cmd":"pm list packages"}`, выполняется в текущем режиме привилегий |
| POST | `/notify` | `{"title":"..","body":".."}` |
| POST | `/agent` | `{"task":"..","session":"необязательный id"}`, возвращает `answer` и `events` |

При подключённом через adb устройстве:

```bash
curl -fsSL https://raw.githubusercontent.com/Azapp888/AzCode/main/tools/install.sh | bash
listen run "Открой настройки и покажи версию Android"
listen screen
listen tap --text "OK"
```

## Приватность и безопасность

- API-ключи моделей, токены GitHub, токены GenOffice и учётные данные Xunfei хранятся только в приватном хранилище приложения; приложение не читает переменные окружения.
- Локальные снимки персонализации создаются на устройстве и никогда не попадают в облачные диалоги.
- Мост привязан только к локальной петле; удалённый доступ опирается на перенаправление adb.
- Онлайн-распознавание Xunfei отправляет аудио на открытую платформу Xunfei; встроенное системное распознавание предпочитает офлайн-обработку на устройстве.
- Shizuku и Root позволяют выполнять системные команды, ошибки могут повредить устройство или данные. Используйте только на устройствах, которыми владеете или на которые имеете явное разрешение.

## Известные ограничения

- Чтение экрана и управление интерфейсом зависят от службы специальных возможностей, которую некоторые производители ограничивают в фоне.
- Системный shell зависит от Shizuku или Root; режим NORMAL ограничен песочницей приложения.
- Аудио- и графический ввод зависят от мультимодальных возможностей выбранной модели.
- Генерация изображений зависит от API провайдеров, поддерживаемые размеры и количество различаются.
- Облачной синхронизации нет, данные удаляются вместе с приложением.
